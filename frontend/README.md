weavroa 图片能力 Web 前端，提供**文生图（插画）**与**图片翻译**两大可视化操作页面。

## 关于我们

超级太乙（https://tyeeai.com/）是一家面向企业提供AI应用落地与数智化转型服务的科技公司。

### 场景推荐

- 插画与营销素材生产：输入描述自动匹配画风，快速产出配图、海报与插画素材
- 跨境内容本地化：上传含文字的图片，将图中文字翻译为目标语言并回填原图版式

## 功能特性

| 页面 | 说明 |
|------|------|
| 文生图（插画） | 输入描述，自动推断画面风格并生成插画，支持流式进度反馈与结果展示 |
| 图片翻译 | 上传图片并选择源/目标语言，轮询翻译任务直至完成并展示翻译后的图片 |

## 技术栈

- Vue 3 + Vite
- vue-router 4

## 快速开始

### 环境要求

- Node.js 20+
- 后端服务 [weavroa-image](../)（默认 `http://127.0.0.1:8080`）

### 安装与运行

```bash
# 安装依赖
npm install

# 开发模式（默认端口 5173，/api 请求代理到 127.0.0.1:8080）
npm run dev

# 生产构建（产物输出到 dist/，路由 base 为 /tool/）
npm run build
```

## 环境变量

`.env.development` 中均为可选配置：

| 变量 | 说明 |
|------|------|
| `VITE_API_BASE_URL` | 后端根地址，所有接口走同一域名时设置（需后端配置 CORS） |
| `VITE_ILLUSTRATION_API_URL` | 文生图接口完整地址，未设置时使用 `/api/v1/image/generate` |

## 目录结构

```
src/
├── assets/            # 页面背景等静态资源
├── pages/
│   ├── illustration/  # 文生图（插画）页
│   └── imageTranslate/ # 图片翻译页
├── utils/             # 流式负载解析、文本与图片地址拆分等工具
└── router/            # 路由配置
```
